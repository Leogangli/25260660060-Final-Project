## 项目概述

本项目为「月度财务关账 → 三大报表生成 → 财务异常检测 → 管理层月度报告」这一典型的财务总监（CFO）周期性任务，设计并实现一个**长程智能体工作流（FinClose Agent Workflow）**。工作流串联 8 个阶段，具备持久化状态与检查点、定时/事件触发、中断恢复、独立核验、人工批准门与有界修订循环等能力，而非一次性脚本。

目标用户为中小型制造/贸易企业的财务总监与财务经理（与本人实际工作场景一致）。所有样例数据均为**合成数据**，不含任何真实客户或公司敏感信息。

## 环境与运行

- Python ≥ 3.11，依赖见 `requirements.txt`（仅 pandas、pyyaml）
- 演示运行：`python3 run.py --period 2026-10`
- 中断恢复演示：`python3 run.py --period 2026-10 --resume`（详见 docs/03 验收清单）
- 测试：`python3 -m pytest tests/ -v`
- 跑测试前需安装开发依赖：`pip install -r requirements-dev.txt`
- 默认使用 Mock LLM（基于规则的可复现输出）；接入真实 LLM 时通过环境变量配置密钥，**密钥不入库**
